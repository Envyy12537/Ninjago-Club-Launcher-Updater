KNOWLEDGE BASE & SUPPORT

FREQUENTLY ASKED QUESTIONS

Everything you need to know about Ninjago City: Open World, installation, and UE5 performance.

01

How do I start the game or select the Unreal Engine 5 build?

The launcher automatically launches the built Unreal Engine 5 executable from the default game directory. Click the green PLAY button on the Library tab to jump right into the game.

02

What are the minimum and recommended system requirements?

MINIMUM REQUIREMENTS

  • OS: Windows 10/11 64-bit
  • CPU: Intel Core i5-8400 / AMD Ryzen 5 2600
  • RAM: 16 GB RAM
  • GPU: GTX 1060 6GB / RX 580
  • DirectX: Version 12
  • Storage: 30 GB SSD

RECOMMENDED (Lumen & Nanite)

  • OS: Windows 11 64-bit
  • CPU: Intel Core i7-12700K / Ryzen 7 5800X
  • RAM: 32 GB RAM
  • GPU: RTX 3070 / 4070 / RX 6800 XT
  • DirectX: Version 12 (Ray Tracing)
  • Storage: NVMe SSD
03

Is this game free and is it affiliated with LEGO?

Ninjago City: Open World is a 100% free non-commercial fan-made project created by passionate fans. All Ninjago characters, lore, and trademarks belong to The LEGO Group.

04

Does the game support co-op multiplayer and controllers?

Yes! The Closed Beta includes 4-player online co-op and full native support for Xbox Wireless Controllers, PlayStation DualSense / DualShock 4, and standard XInput gamepads.

05

How to boost FPS and enable DLSS / FSR 3 / TSR?

In the in-game settings menu under Video -> Upscaling, you can enable NVIDIA DLSS Super Resolution & Frame Generation, AMD FSR 3, or Epic TSR. For mid-range GPUs, setting Global Illumination to High yields a massive performance boost.

06

How do I report bugs or submit feedback to the developers?

Join our official Discord server and post your crash logs or gameplay clips in the #beta-feedback and #bug-reports channels.
